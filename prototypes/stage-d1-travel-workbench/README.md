# D1 高保真原型

这是与现有 Streamlit/FastAPI 业务代码隔离的产品原型，不会调用真实 API，也没有重新实现规划或评分算法。

在本目录启动静态服务：

```powershell
python -m http.server 8890
```

然后访问 `http://127.0.0.1:8890/`。原型为零外联、无构建依赖的 HTML/CSS/JavaScript，示例内容来自 C3 固定 Fixture，并在界面中持续标记为 Mock。

覆盖：需求输入、多轮澄清、偏好确认、整体规划状态、双方案比较、单/双方案详情、推荐/并列/仅一套可行/无法推荐、天气不可用、预算不可满足、Agent 错误和网络错误。
