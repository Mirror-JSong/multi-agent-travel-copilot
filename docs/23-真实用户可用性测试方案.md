# Multi-Agent Travel Copilot 真实用户可用性测试方案

## 1. 研究状态

**待执行。** 当前没有真实参与者记录，因此不报告任务成功率、完成时间、满意度或用户理解率。
自动化测试、模型生成反馈和研究者预设答案均不得录入为真人数据。

建议招募 3～5 位对自助旅行规划有经验、但未参与本项目开发的测试者。参与者只使用代号
`P01` 等，不收集姓名、联系方式、单位等完成研究不需要的信息。

## 2. 研究问题

1. 用户能否理解自然语言输入、系统追问和最终确认之间的关系？
2. 修改预算或人数后，用户能否判断旧结果已经失效并完成重新规划？
3. 用户能否复述双方案推荐依据，并区分评分、硬约束与个人选择？
4. 用户能否正确理解预算不可满足、天气不可用、并列和程序失败？

## 3. 测试准备

- 使用同一固定 Mock 数据版本和本地正式 FastAPI/Streamlit。
- 明确告知：数据不是实时价格、库存或天气，选择方案不代表预订。
- 获得参与者对观察、计时和匿名记录的明确同意。
- 主持人不得提前演示具体点击路径；只在参与者明确卡住时提供最小帮助并计数。
- 每场约 25～35 分钟：介绍 3 分钟、任务 15～20 分钟、访谈 7～10 分钟。

## 4. 四项核心任务

### 任务 A：自然语言旅行需求

给参与者需求卡：“从上海出发，国庆与朋友旅行五天，预算 15000 元，喜欢摄影和美食，
不想太累。”要求其得到一份可确认的旅行偏好，不提供点击步骤。

完成标准：提交自然语言；回应系统追问；能指出出发日、返程日、人数、预算和 pace；完成
偏好确认。遗漏必要字段或未经确认进入规划均算未完成。

### 任务 B：修改旅行偏好

要求将预算改为 10000 元或将人数改为 3 人，并重新生成结果。

完成标准：修改进入新签名草稿；旧规划/评分不再作为当前结果；新结果使用更新值。若继续
引用旧推荐，或修改未生效，算未完成。

### 任务 C：双方案比较

要求比较两个目的地，解释费用、兴趣、天气和旅行节奏差异，并自主选择一个进一步查看。

完成标准：能说出推荐类型；至少正确复述两个有证据维度；能打开所选方案详情；明确知道
该选择不是预订。

### 任务 D：异常信息理解

依次提供一张预算不可满足、天气不可用或并列结果卡（由固定 Mock 场景真实产生），要求
参与者解释含义和下一步行动。

完成标准：不把天气不可用理解为晴天；不把预算无解理解为程序故障；不把并列理解为系统
偷偷选择了胜者；能够提出修改预算/偏好、重试或查看事实等合理操作。

## 5. 主持人记录规则

每项任务记录：

- `completed`：是否达到上述完成标准。
- `duration_seconds`：主持人读完任务后开始，到达到完成标准或主动放弃为止。
- `error_count`：导致偏离目标的可观察操作。
- `assistance_count`：主持人提供最小提示的次数。
- `misunderstanding_notes`：原话或近义记录，不做心理推断。
- `recommendation_basis_correct`：只在任务 C/D 可评价；否则填 `n/a`。
- 主观反馈与主持人观察分列，避免把研究者解释写成用户观点。

记录模板：[D3-用户可用性测试记录模板.csv](templates/D3-用户可用性测试记录模板.csv)。

## 6. 测试后访谈

1. 哪一步最清楚？哪一步最不确定？为什么？
2. 系统为什么推荐、并列或不推荐某个方案？
3. 你如何理解四维评价与总分之间的关系？
4. 天气不可用与天气恶劣有什么区别？
5. 如果预算不可满足，你下一步会做什么？
6. 哪些信息让你误以为可以真实预订？
7. 如果下次使用，你最希望减少或增加哪一步？

主观问题不使用诱导式措辞，不要求参与者赞同系统。

## 7. 统计口径

在 `python/` 目录执行：

```bash
python experiments/analyze_usability_results.py \
  ../docs/templates/D3-用户可用性测试记录模板.csv \
  --output experiments/results/d3_usability_results.json
```

脚本按任务输出完成率、平均/中位时间、错误和协助次数，并单独计算可评价记录中的推荐依据
理解率。空模板返回 `pending_real_participants`，不会产生零成功率或伪造结论。

样本仅 3～5 人时报告逐人记录、分子/分母和描述性统计，不做显著性检验，不外推总体用户。

## 8. 隐私与停止条件

- 只保存参与者代号和经同意的任务数据。
- 不录制音视频，除非单独获得明确许可并规定删除日期。
- 参与者可随时停止，停止不需要说明理由。
- 发现密钥、账户或个人旅行信息时立即停止记录并删除该字段。
- 未完成真实测试前，作品集统一写“已准备可执行方案，真人研究待开展”。
