## 5. 数据一致性与异常边界

- 比较卡片、解释、行程详情和预算组件读取同一份 API 结果；前端不重算评分或费用。
- 方案切换只切换已有 `DestinationPlan`，不会重新请求 Pipeline。
- `COMPLETED`、`BUDGET_INFEASIBLE`、活动约束、pace 约束和 `FAILED` 保持独立语义。
- 天气 unavailable 与 Provider timeout 都显式降级，均不伪装为晴天。
- 晴雨测试使用相同候选版本；晴天和雨天活动候选 ID 及总费用差异可追溯。
- HMAC 回执继续绑定完整草稿、日期基准与 Parser 配置；密钥未发送给客户端或写入结果。
- UI 持续显示 Mock、非实时、非预订边界。
