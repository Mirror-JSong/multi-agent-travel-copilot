# Multi-Agent Travel Copilot 最终产品实验与证据汇总

## 1. 证据边界

本报告的数据均由 2026-09-26 重新运行现有实验脚本生成，并由
`experiments/summarize_d3_evidence.py` 从原始 JSON 再聚合。它们是固定 Mock 自动化实验，
不代表真实 LLM 泛化能力、真实市场准确性、生产性能或用户满意度。

证据分三层：

1. 固定 Mock 自动化实验：可重复的规则、契约和指标。
2. 真实 HTTP / 浏览器功能验证：证明本地正式服务链路可运行。
3. 真人可用性测试：当前无参与者记录，状态为待执行。

汇总原始文件：`python/experiments/results/d3_product_evidence_summary.json`。

## 2. 阶段 A：偏好澄清

| 指标 | 重算结果 | 正确解释 |
|---|---:|---|
| 必要字段收集完成率 | 8/8（100%） | 固定 8 场景最终均形成完整草稿 |
| 已支持字段提取准确率 | 51/51（100%） | 只针对人工标注、规则支持的字段 |
| 漏提取 / 错提取 / 误报 | 0 / 0 / 0 | 不能外推开放域中文 |
| 澄清轮次 | 5 次，总场景均值 0.625 | 自动化补充轮次，不是人均对话负担 |
| 自然语言原子步骤 | 34，总均值 4.25 | 按预定义输入/点击口径 |
| 结构化原子步骤 | 61，总均值 7.625 | 同一固定字段口径 |
| 规划结果一致性 | 8/8（100%） | 规范化偏好一致时入口结果一致 |
| 异常恢复 | 7/7（100%） | 包含冲突、非法值、回执篡改和网络失败重试 |

自然语言流程在该固定口径下少 27 个原子步骤；这不是实际用户节省时间，也不能推导满意度。

## 3. 阶段 B：天气对照实验

Control 与 Treatment 保持用户偏好、天气记录、活动候选、价格、版本和预算一致，唯一变量
是天气是否参与活动过滤与排序。

| 指标 | Control | Treatment |
|---|---:|---:|
| 天气冲突率 | 33/63（52.38%） | 0/60（0%） |
| 兴趣匹配率 | 63/69（91.30%） | 48/66（72.73%） |
| 预算合规 | 12/13（92.31%） | 11/13（84.62%） |
| 天气可验证可行 | 1/13（7.69%） | 11/13（84.62%） |
| 天气决策解释覆盖 | 不适用 | 34/34（100%） |

收益是消除已评价活动的硬天气冲突；代价是固定候选池内兴趣匹配和预算合规有所下降，且有
1 个 Treatment 场景变为 `ACTIVITY_CONSTRAINTS_UNSATISFIED`。逐场景费用没有被平均数
隐藏：雨天室内替代可增加 360 元，东京混合天气增加 700 元，也存在曼谷序列场景减少
40 元等情况。完整 13 条记录保存在 `weather_awareness_results.json`。

真实 HTTP 固定场景复验：晴天总费用 1550 元、雨天 1910 元，活动 candidate_id 集合不同；
天气不可用保留 `unavailable`，超时保留 `degraded_timeout`，均未伪装成晴天。

## 4. C0：旅行节奏

同一核心候选池的实际差异：

| pace | 每日活动 | 休息 | 已知高强度活动 | 总费用 | 状态 |
|---|---:|---:|---:|---:|---|
| 未指定 | 3 + 3 | 0 | 0 | 3169 | COMPLETED |
| relaxed | 2 + 2 | 2 | 0 | 3129 | COMPLETED |
| balanced | 3 + 3 | 0 | 0 | 3169 | COMPLETED |
| packed | 3 + 3 | 0 | 6 | 2929 | COMPLETED |

专项集合共 11 场景；relaxed 包含预算不可满足和 pace 不可行边界。结果仅证明规则产生预期
差异，不是实际舒适度测量。

## 5. 阶段 C：双方案与解释

C2 三组固定评价结果分别是 `recommended`、`only_feasible` 和
`no_recommendation`。同一原始方案把预算权重提高 5 个百分点、兴趣权重降低 5 个百分点，
决策由 `recommended` 变为 `tie`，证明该场景对权重敏感，系统应披露而非包装成绝对结论。

C3 七组产品实验重算：

| 指标 | 结果 |
|---|---:|
| 两套均完成场景 | 3/7（42.86%） |
| 评价证据完整 | 30/30（100%） |
| 解释一致 | 7/7（100%） |
| 比较状态识别正确 | 7/7（100%） |
| 四维差异信息覆盖 | 24/24（100%） |
| 敏感性字段披露 | 7/7；1 场景发生决策变化 |

本次本机执行时间：单方案 Control 合计 19.9512 ms，双方案 Treatment 合计 113.8490 ms；
逐场景额外耗时 6.5326～17.7747 ms。该计时只包含固定内存 Mock 和当前机器，不应当作为
外部 API 或生产延迟预测。

## 6. 正式服务与浏览器证据

- `d3_service_acceptance.json`：真实 TCP 请求完成多轮澄清、HMAC 防篡改、自然语言比较、
  高/中/低预算、偏好修改和天气不可用。
- `d3_weather_status_http.json`：显式启用的固定 Mock 验收端点覆盖晴/雨、unavailable、
  timeout、无可行活动和 Agent 故障；普通运行隐藏该端点。
- `d3_agent_failure_http.json`：独立受控 Uvicorn 中一套完成、一套 `FAILED`，保留
  FlightAgent、错误类型与原因。
- `d3_browser_acceptance.json`：真实 Edge 驱动 Streamlit，从自然语言到双方案详情；桌面和
  390×844 窄屏断言均通过。
